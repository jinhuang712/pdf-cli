# M1.2 — The text layer, the font check and the space repair

- **Landed:** 2026-10-15 in `e27f495`, with review fixes in `abbfd69`.
- **Written:** after the fact, on 2026-10-15.

## What was built

- Each parsed page stores its text layer: lines with their boxes, grouped into paragraph-like blocks. Ligatures are spelled out, invisible characters removed, spaces made plain and accents composed.
- A hyphen at a line's end joins its word when the page or macOS's word list knows the joined word, so "exam-ple" becomes "example" and "self-attention" keeps its hyphen.
- The font check measures each word gap in a page's text operations against half its body font's declared space, with `CGPDFScanner`. A file with 5% risky gaps, or a page with 10%, gets the space repair: PDFKit's characters with Apple OCR's word breaks.
- Parser version 2, cache schema 2.

## Review

The reviewer reproduced findings 1 and 2.

| # | Finding | Verdict | Resolution |
|---|---|---|---|
| 1 | Whether a page got the space repair depended on which file was read first, since results were keyed by page alone. Caches made before this change never got the repair, because the at-risk mark was written only when a document row was first created. | High, confirmed | Fixed: a page in an at-risk file is cached under its own key; upgrading a version-1 cache forgets file entries so every file gets the check; indexing again updates a document's verdict. |
| 2 | Rotated pages rendered clipped for OCR, so the repair found fewer spaces. | Medium-high, confirmed | Fixed: pages render upright. A test shows a rotated page gets at least 90% of the upright page's spaces. |
| 3 | The font check had no work limit: forms drawing forms could take about 10⁶ scans, and a slow check inside the index pass could time the page out as a permanent failure. | Medium, likely | Fixed: each form is read once and its counts reused, and the work is capped. |
| 4 | The guard for hyphenated words was dead code, so "data-" + "set" joined to "dataset" even where the page spells "data-set". | Low-medium, confirmed | Fixed: a compound the page spells with a hyphen keeps it. |
| 5 | A lone dash at a line's end joined the next word. | Low | Fixed: it stays a separate word. |
| 6 | A font set inside a form leaked into the page around it. | Low | Fixed. |
| 7 | A page with a zero-size crop box lost all its text. | Low | Fixed: it keeps its text. |
| 8 | A lone lead surrogate skipped the next character. | Low | Fixed. |
