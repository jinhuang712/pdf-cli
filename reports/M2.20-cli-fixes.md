# M2.20 Small command-layer fixes

## Built
1. `pdf crop` ends 3 for every file that does not open (locked, not a PDF, damaged, slow), also a cached file made unreadable; a page that cannot be drawn ends 1.
2. `pdf dump` of a locked, added file: `--markdown`, `--text`, `--notes` and `--refs` still come from the cache without the password; `--figures`, `--tables`, `--attachments` and `--scripts`, which need the file, end 3 with the hint. No up-front gate (review H1).
3. Unlock hints are the command as typed plus `--password-stdin` (`Contract.unlockHint`); a wrong password is told that it does not open the file, not to do again what it just did.
4. `pdf transcribe` checks the file (exists; readable unless cached) before reading standard input.
5. `pdf rm --json` gives `id` and `title`; `pdf agent-guide --install --json` gives the text's warnings word for word and a `hint` (the `/reload-skills` line).
6. `pdf read --refs end`: on a provisional read with nothing listed, the summary says no list was seen in the pages parsed so far, only when the judged index holds no entry (`Document.listEntries`). I chose to say so, not to parse the list's pages.
7. `--show raw` labels a replaced layer `[PDF text layer]`; the summary says "replaced text layer". A scan's old OCR layer and a born-digital page's own text cannot be told apart without a parser change, so both carry this label. JSON names `old-ocr` and `oldOCRLayers` are kept.
8. `Reader.resolve` writes `/private/{tmp,var,etc}` as `/tmp`, `/var`, `/etc` whether or not the file exists; `rm` compares library paths the same way. `dump -o /tmp` (and `/var`, `/etc`) is accepted; a link as the folder itself is still refused.
