# M2.18 `--dry-run` on pick, transcribe and rm

## Built
- `--dry-run` on `pdf pick`, `pdf transcribe` (and `--clear`) and `pdf rm`: text starts `dry run: `; under `--json` the real run's keys plus `"dryRun": true`; the real run's exit code and failure shape on a miss. Extra keys, only in a dry run: `replaces` (always present, null when nothing is replaced: pick gives the earlier letter, transcribe the earlier reading's day), `characters` (transcribe), `picksKept`, `transcriptsKept`, `sharedWith` (rm).
- It answers only from what is kept (plan/decisions/050-a-dry-run-answers-from-what-is-kept-and-never-parses.md → Decision: a dry run answers from what is kept and never parses). `Reader.peek` reads the cache without parsing, starting a runner or registering the file. `Store(readOnly:)`, `Picks`, `Transcripts` and `Library` open read-only and create nothing; `rm` counts with SELECTs (`Store.wouldRemove`) that mirror its deletes. A cache from an older schema, a leftover journal (SQLite 8) or missing log files (SQLite 14) fail in one sentence, exit 1.
- Not cached: three messages, for a never-read file, a file changed since it was read (or `pdf` updated), and a page not parsed yet; only the last names `--page N`.
- Transcribe reads and checks stdin as the real run does and reports its size.
- Help examples, the agent guide (`--dry-run` named once; a test checks it names the commands whose help has the flag), FEATURES F7, F11, pick and transcribe, ROADMAP.

## Tests
`scripts/test.sh -j 2 --filter "DryRunTests|OutputContractTests|AgentGuideTests|StoreTests|LibraryTests|TranscriptsTests"`: 56 passed. `DryRunTests` snapshots every file under the home (bytes, so the database header and log too, plus `user_version`; the `-shm` by size only) before and after each dry run, and finds them equal; the real run then does what the dry run said. Cases: keys and values equal to the real run; misses with the same output and code; an older cache (`user_version=7` stays 7); a missing file on an empty home (`no such file`, nothing created); a changed file; a never-read file with page 99; a file only the cache knows; a cache with its log files gone; an empty home creates nothing. `test-cache.sh` not run.
