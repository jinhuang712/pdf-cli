## What was built

- OCR'd pages get a second reading: the older text recognizer on macOS 26, the same recognizer at 70% size before that. Their word agreement, per page and per block, decides the verdict, with threshold 0.85.
- A page whose words run together gets the space repair too. Unsure breaks the word list backs, and words both readers run together that split into common English words, become unsure spans with two readings.
- `Quality.judge` gives each page ok, unsure, low-quality or failed, with reasons and scores, at read time.
- The output writes failure blocks with crop and `--raw` commands, unsure blocks with `pdf pick` and look commands, picked words in place, `--raw` with `[low-quality]` and `[old OCR]`, and exit codes 0, 2 and 3.
- `pdf pick` saves the agent's choice in Application Support; a pick applies only while the page offers the same readings.
- Files PDFKit made or saved get a warning in the summary line.
- Parser version 4, cache schema 4.

## Review

The reviewer found nothing that puts wrong text into the output. It ran the 75 unit tests and probe tests in a copy of the package.

| # | Finding | Verdict | Resolution |
|---|---|---|---|
| 1 | Run-together words with no clean split went out unflagged, as in "Twoprompttemplateswereusedthroughouttheexpe" on arXiv 2608.24191 p.13. DESIGNS rejects exactly that. | Confirmed | Fixed: English-looking run-together words get an unsure span with their one reading and a look crop. German compounds stay unmarked. |
| 2 | After one mismatch in a block, every later unsure break was dropped, because a line-end hyphen could join differently in the two readings. | Likely | Fixed: the walk compares words with hyphens left out. |
| 3 | Correct code names and web addresses got split and flagged, as in "Space Repair Relocate Run Together Words". | Confirmed at unit level | Fixed: web addresses, paths, names with underscores and names with three or more inner capitals get no second reading. |
| 4 | DESIGNS said "20 words" where the code counts 20 units (words of 4+ letters), and "in any script" where only English was measured. | Confirmed | Fixed in DESIGNS. |
| 5 | A misused command exits 64; FEATURES said 1. | Confirmed | Docs follow the code: 64 for misuse, 1 for a command that could not run. |
| 6 | Paths starting with `~` or `-` were not quoted in suggested commands. | Confirmed | Fixed. |
| 7 | A page with no block shown could exit 2 instead of 3. | Likely, minor | Fixed: exit 3 needs a page with no text shown. |
| 8a | A break beside an accented letter counted, so "caféchat" got the reading "café chat". | Confirmed | Fixed: only maths letters count. |
| 8b | DESIGNS said every failure block names `--raw`; failed pages have no text to show. | Doc gap | Fixed in DESIGNS. |
